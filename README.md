# murad-menu

منيو مطعم وكافيه مراد — صفحة ويب بالعربي والإنجليزي.

## بنية المشروع

```
index.html        هيكل الصفحة (صفحة الدخول بالفيديو + المنيو بتصميم "صحون")
css/style.css     التصميم
js/app.js         الكود (عرض المنيو، البحث، اللغة، صفحة الدخول)
data/menu.json    كل محتوى المنيو: المجموعات، الأقسام والأصناف
img/              اللوغو وصور الأقسام والأصناف
v/                فيديو صفحة الدخول (landing.mp4) وصورته (landing.jpg)
demo/             التصاميم التجريبية
```

## تعديل المنيو — `data/menu.json`

كل تعديل على الأصناف أو الأسعار بيصير بهالملف بس، بدون ما نلمس الكود.

### `sections` — الأقسام

| الحقل | المعنى |
|---|---|
| `ar` / `en` | اسم القسم بالعربي / بالإنجليزي |
| `g` | المجموعة اللي بينتمي إلها: `kitchen` · `cafe` · `sweet` · `feast` |
| `c` | صورة القسم |
| `compact` | `true` = صحون صغيرة، تلاتة بالصف، مناسب للمشروبات والأركيلة |
| `items` | الأصناف |

### `items` — الأصناف

| الحقل | المعنى |
|---|---|
| `ar` / `en` | اسم الصنف |
| `d` / `de` | الوصف بالعربي / بالإنجليزي (اختياري) |
| `p` | السعر بالدينار العراقي — `0` يعني "حسب الطلب" |
| `i` | مسار الصورة (فاضي = بدون صورة) |
| `s` | `true` = صنف "توقيع مراد" (شارة حمرا تحت الاسم) |
| `best` | `true` = بيطلع كمان بقسم "الأكثر مبيعاً" بأول المنيو |
| `n` / `ne` | ملاحظة قصيرة بالعربي / بالإنجليزي، بتطلع تحت اسم الصنف (مثلاً: فقط يوم الجمعة أو عند الطلب) |

### `groups` — المجموعات الأربعة

`k` المفتاح، و`ar`/`en` الاسم اللي بيطلع كفاصل بين المجموعات بالمنيو.

### `halls`

من صفحة الدخول القديمة، ومش مستخدمة حالياً.

## التشغيل محلياً

الصفحة بتحمّل `data/menu.json`، فلازم تنفتح من سيرفر (مش بالدبل كليك على الملف):

```bash
python3 -m http.server 8000
```

وبعدين افتح http://localhost:8000
