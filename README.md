# murad-menu

منيو مطعم وكافيه مراد — صفحة ويب بالعربي والإنجليزي.

## بنية المشروع

```
index.html        هيكل الصفحة (صفحة الدخول + المنيو)
css/style.css     التصميم
js/app.js         الكود (عرض المنيو، البحث، اللغة، صفحة الدخول)
data/menu.json    كل محتوى المنيو: المجموعات، الصالات، الأقسام والأصناف
img/              صور الأقسام والأصناف (webp) — ناقص اللوغو img/logo.png
v/                فيديوهات صفحة الدخول والصالات (لازم تنضاف)
```

## تعديل المنيو — `data/menu.json`

كل تعديل على الأصناف أو الأسعار بيصير بهالملف بس، بدون ما نلمس الكود.

### `sections` — الأقسام

| الحقل | المعنى |
|---|---|
| `ar` / `en` | اسم القسم بالعربي / بالإنجليزي |
| `g` | المجموعة اللي بينتمي إلها: `kitchen` · `cafe` · `sweet` · `feast` |
| `c` | صورة القسم |
| `compact` | `true` = عرض مختصر (صورة صغيرة دائرية وبدون وصف)، مناسب للمشروبات |
| `items` | الأصناف |

### `items` — الأصناف

| الحقل | المعنى |
|---|---|
| `ar` / `en` | اسم الصنف |
| `d` / `de` | الوصف بالعربي / بالإنجليزي (اختياري) |
| `p` | السعر بالدينار العراقي — `0` يعني "حسب الطلب" |
| `i` | مسار الصورة (فاضي = بدون صورة) |
| `s` | `true` = صنف "توقيع مراد" (إطار أحمر وشارة) |

### `groups` — المجموعات الأربعة

`k` المفتاح، `ar`/`en` الاسم، `sa`/`se` السطر الصغير تحت الاسم، `tile` اسم القسم اللي صورته بتطلع على مربع المجموعة بصفحة الدخول.

### `halls` — الصالات بصفحة الدخول

`v` اسم الفيديو (`v/<v>.mp4` و `v/<v>.jpg`)، `ar`/`en` الاسم، `da`/`de` الوصف.

## التشغيل محلياً

الصفحة بتحمّل `data/menu.json`، فلازم تنفتح من سيرفر (مش بالدبل كليك على الملف):

```bash
python3 -m http.server 8000
```

وبعدين افتح http://localhost:8000
